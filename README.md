# Pemantauan & Pengelolaan PJP

Aplikasi web untuk memantau dan mengelola Perusahaan Jasa Pertambangan (PJP), dibangun dengan Next.js.

Terdiri dari 3 tahapan utama:
1. Persyaratan, Seleksi, dan Penetapan
2. Tanggung Jawab, Pemantauan, dan Pelaporan
3. Evaluasi

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.
